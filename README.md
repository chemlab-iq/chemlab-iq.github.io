# المختبر الافتراضي للكيمياء التحليلية
**Virtual Analytical Chemistry Lab** — مختبر تفاعلي للجزء العملي من الكيمياء التحليلية: 13 تجربة خطوة بخطوة مع الشك بالقياس، ومراجعة وامتحان تجريبي.

- الموقع: https://atheerhamza93-ai.github.io/analytical-chemistry-lab/
- `index.html` — الصفحة الجاهزة (ملف واحد).
- `src/` — ملفات المصدر وتعليمات البناء (`src/README.md`). البناء: `node build_free.js` ثم نسخ الناتج إلى `index.html`.
